Aqui você gerencia os dados que são exibidos no portal para os alunos. Use o menu lateral para cadastrar ou editar Projetos de Pesquisa, Projetos de Extensão e Eventos do Calendário.

Estes dados complementam as informações que vêm diretamente do SUAP, preenchendo lacunas ou adicionando registros locais.
